# Баг-репорты математического тренажёра

**Сайт:** https://daniil2243.github.io/math-trainer/

## BUG-001 Некорректная запись `5..0` засчитывается как правильный ответ

**Статус:** открыт.

**Где воспроизведено:** 2025 год → задача № 5 «Шахматная матрица» → поле ответа `det A`.

**Предусловие:** задача ещё не отмечена решённой.

**Шаги воспроизведения:**

1. Выбрать 2025 год.
2. Открыть задачу № 5 «Шахматная матрица».
3. Ввести `5..0` в поле `det A`.
4. Нажать «Проверить ответ».

**Ожидаемый результат:** сайт сообщает о некорректной записи ответа. Задача не засчитывается, число решённых задач не увеличивается.

**Фактический результат:** появляется сообщение «Верно. У тебя получилось!». Задача отмечается решённой, число решённых задач увеличивается.

**Примечание:** правильный ответ задачи — `0`, однако `5..0` не является корректной записью числа.

## BUG-002 Открытие разбора после самостоятельного решения изменяет способ решения в результатах

**Статус:** открыт.

**Где воспроизведено:** «Разминка · основы» → задача № 4 «Расстояние без рисунка» → окно «Твои результаты» и сводка прогресса.

**Предусловие:** задача ещё не решена; подсказки и полный разбор не открывались.

**Шаги воспроизведения:**

1. Открыть задачу «Расстояние без рисунка».
2. Ввести правильный ответ `5` и нажать «Проверить ответ».
3. Убедиться, что число самостоятельных решений увеличилось.
4. Нажать «Открыть полный разбор».
5. Открыть «Посмотреть результаты» и проверить статус задачи.
6. Закрыть окно результатов и перезагрузить страницу.

**Ожидаемый результат:** задача остаётся решённой самостоятельно. Просмотр разбора после решения не изменяет способ решения и не уменьшает число самостоятельных решений.

**Фактический результат:** в результатах появляется статус «Решено после разбора». После перезагрузки число самостоятельных решений уменьшается, а число решений с подсказками или разбором увеличивается.

## BUG-003 Браузерная кнопка «Назад» не восстанавливает задачу исходной страницы

**Статус:** открыт.

**Предусловие:** сайт открыт по основному адресу без фрагмента `#…`. На странице отображается ранее выбранная задача «Расстояние без рисунка».

**Шаги воспроизведения:**

1. Через список задач открыть «Первую функцию без угадывания».
2. Убедиться, что адрес заканчивается на `#warm-function`.
3. Нажать браузерную кнопку «Назад».

**Ожидаемый результат:** адрес возвращается к исходному, на странице снова отображается «Расстояние без рисунка».

**Фактический результат:** адрес возвращается к исходному, но на странице остаётся «Первая функция без угадывания».

**Примечание:** проблема воспроизведена при возврате к исходной записи истории, адрес которой не содержит фрагмента `#…`.

## BUG-004 Формула с неопределённым выражением засчитывается как правильная

**Статус:** открыт.

**Где воспроизведено:** «Разминка · основы» → задача № 3 «Первая функция без угадывания» → поле ответа `f(x)`.

**Предусловие:** задача ещё не отмечена решённой.

**Шаги воспроизведения:**

1. Открыть задачу «Первая функция без угадывания».
2. Ввести `3*x+ln(0)-ln(0)` в поле `f(x)`.
3. Нажать «Проверить ответ».

**Ожидаемый результат:** сайт не принимает ответ и сообщает о недопустимом выражении. Задача не засчитывается.

**Фактический результат:** появляется сообщение «Верно. У тебя получилось!». Задача отмечается решённой.

**Примечание:** правильная функция — `3*x`. Однако `ln(0)` не определён, поэтому выражение `ln(0)-ln(0)` нельзя считать нулём.

## BUG-005 Сохранение черновика во второй вкладке удаляет черновик другой задачи

**Статус:** открыт.

**Где воспроизведено:** раздел «Черновик» при одновременной работе в двух вкладках одного браузера. Проверено на задачах «Первая функция без угадывания» и «Расстояние без рисунка».

**Предусловия:**

- Сайт открыт в двух вкладках одного профиля браузера.
- В первой вкладке открыта «Первая функция без угадывания».
- Во второй вкладке открыто «Расстояние без рисунка».
- Обе вкладки загружены до начала ввода тестовых записей.

**Шаги воспроизведения:**

1. В первой вкладке раскрыть «Черновик» и ввести `Тестовый черновик A`.
2. Перезагрузить первую вкладку и убедиться, что запись сохранилась.
3. Перейти во вторую вкладку, не перезагружая её.
4. Раскрыть «Черновик» и ввести `Тестовый черновик B`.
5. Вернуться в первую вкладку и перезагрузить её.
6. Проверить черновик задачи «Первая функция без угадывания».

**Ожидаемый результат:** сохраняются оба черновика. Запись в одной задаче не удаляет сохранённые заметки другой задачи.

**Фактический результат:** черновик первой задачи становится пустым после сохранения записи во второй вкладке и последующей перезагрузки первой.

**Примечание:** в контрольной проверке с одной вкладкой черновик сохранялся после перезагрузки. Потеря записи повторилась после ввода во второй, заранее открытой вкладке.
