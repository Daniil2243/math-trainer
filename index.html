Под рукой

Раскрытие квадратов

Каждый член первой скобки умножь на каждый член второй.

(a − b)² = a² − 2ab + b²
(a + b)² = a² + 2ab + b²

При вычитании скобки знак меняется у каждого её слагаемого: −(a − b) = −a + b.

Координаты и окружности

x и y — координаты точки, которую мы ищем. Известные координаты других точек им не мешают.

(x − a)² + (y − b)² = R²

Центр — (a, b), радиус — R. Вычитая два уравнения, вычитай всю левую часть из всей левой и всю правую из всей правой.

Функциональные уравнения

f — правило, которое каждому аргументу выдаёт число. f(0) — одно число; f(x) — значение при неизвестном x.

  1. Проверь x = 0 и y = 0.
  2. Попробуй поменять x и y местами.
  3. Сделай сложный аргумент нулём.
  4. Проверь найденную формулу в исходном условии.

f(x) = C значит, что функция выдаёт одно и то же число при любом x. Найти пару примеров недостаточно: нужно объяснить, почему других решений нет.
