# Математика по шагам · ИТМО

Интерактивный тренажёр: 15 задач региональной студенческой олимпиады СПб в ИТМО за 2020–2025 годы и 4 авторские разминки. Есть выбор года и темы, проверка ответа, поэтапные подсказки и черновик. Это подборка, а не полный архив.

## Первая публикация через браузер

1. Создай бесплатный аккаунт на https://github.com/signup и подтверди почту.
2. Создай новый репозиторий с названием `itmo-trainer`. Выбери `Public` и включи создание README.
3. Распакуй архив на компьютере. В репозитории открой `Add file` → `Upload files`.
4. Загрузи файлы из распакованной папки прямо в корень репозитория: `index.html` должен быть на одном уровне с `app.js`, `bank.js`, `engine.js` и `style.css`. Загружать сам ZIP или помещать сайт в дополнительную вложенную папку не нужно. Сохрани загрузку кнопкой `Commit changes` (или подтверди предложенные изменения, если интерфейс использует `Propose changes`).
5. Открой `Settings` → `Pages`. В `Source` выбери `Deploy from a branch`, затем ветку `main` и папку `/(root)`. Нажми `Save`.
6. Дождись успешной публикации. GitHub покажет ссылку вида `https://ТВОЙ-НИК.github.io/itmo-trainer/` в разделе Pages. Именно этой ссылкой можно делиться.

Официальные инструкции:
- Аккаунт: https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github
- Загрузка файлов: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
- Настройка Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что проверяется

Тренажёр проверяет числовые ответы, поддерживаемые формулы и координаты. Проверка учитывает равносильные многочлены и некоторые записи логарифмов. Числовые приближения допускаются с относительной погрешностью около 0,001%; целые ответы проверяются строже. Доказательства и произвольные текстовые решения автоматически не оцениваются.

Полный разбор открывается по отдельной кнопке после всех подсказок или правильного ответа. PDF-источники могут содержать официальные решения, о чём сказано в названии ссылок.

Каждый посетитель получает собственный прогресс в своём браузере. Прогресс не синхронизируется между устройствами. Есть выгрузка прогресса в JSON.

## Устройство проекта

- `index.html` — разметка страницы.
- `style.css` — оформление и адаптация под телефон.
- `app.js` — действия кнопок и сохранение прогресса.
- `bank.js` — условия, подсказки, учебные решения и источники.
- `engine.js` — безопасный разбор и проверка ответов.

Для публикации не нужны терминал, установка Python или сборка проекта. Сайт работает из статических файлов.

Источник задач: https://im.itmo.ru/ru/events/olymp_spb
